## 🛡️ Featured project

### [XGuard IDS](https://github.com/kalbasha786/xguard-ids)
My final year project. An intrusion detection system that classifies network flows with **XGBoost**, blocks attackers with **iptables**, alerts staff on **Telegram**, and gives staff a role based web control panel built with **Streamlit**.

- 99.94% accuracy and 0.98 macro F1 on 676,617 unseen CICIDS2017 test records
- Found and fixed a known labelling problem in the dataset, raising Web Attack F1 from 0.25 to 0.93
- Blocks before it alerts, never blocks its own gateway, and keeps an audit trail of every release
- Dashboard with login, viewer, analyst and admin roles, account lockout and an activity log
